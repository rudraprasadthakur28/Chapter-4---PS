# Python Chapter 4 — Practice Set

This repository contains my solutions to the **Python Chapter 4 Practice Set**.

The exercises focus on lists, list operations, sorting, tuples, tuple immutability, summing list elements, and counting specific values in a tuple.

## Questions Covered

### 1. Store Seven Fruits in a List

Write a Python program to store seven fruits in a list. The fruit names should be entered by the user.

### 2. Sort Student Marks

Write a Python program to accept the marks of **6 students** and display them in sorted order.

### 3. Tuple Immutability

Write a Python program to demonstrate that the values of a tuple cannot be changed after the tuple has been created.

### 4. Sum a List

Write a Python program to find the sum of a list containing **4 numbers**.

### 5. Count Zeros in a Tuple

Write a Python program to count the number of zeros in the following tuple:

```python id="r2w9kh"
a = (7, 0, 8, 0, 0, 9)
```
